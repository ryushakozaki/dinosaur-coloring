# きょうりゅう自由ぬりえ Webサイト

4歳くらいから遊べる、タップだけの恐竜ぬりえゲームです。

## 特徴
- ティラノサウルス、トリケラトプス、ステゴサウルス、スピノサウルス、ヴェロキラプトル、パラサウロロフス、アンキロサウルス、ブラキオサウルス、プテラノドン、カルノタウルスの10種類
- 数字に従う方式ではなく、好きな色を好きなパーツにタップして着色
- 23色のカラーパレット
- 「もどす」「さいしょから」「しろにもどす」「できあがり」
- スマホ／iPhoneのタップ操作を優先したUI
- 外部ライブラリ不要
- PWA対応（HTTPSで公開するとホーム画面に追加可能）

## 公開方法（おすすめ：GitHub Pages）
1. GitHubで新しいPublicリポジトリを作る
2. このフォルダの `index.html` `manifest.json` `sw.js` をアップロード
3. Settings → Pages → Deploy from branch → main / root を選ぶ
4. 表示されたURLをiPhone Safariで開く

## Netlify / Vercel
この3ファイルが入ったフォルダをそのままドラッグ＆ドロップ／デプロイできます。

※今回の恐竜絵はWeb上で自由に配布できるよう、外部の既存イラストを転載せず、恐竜の特徴をもとにしたオリジナルのベクター線画です。
